所有知识库、文档版本和向量必须按 ent_code 隔离。向量检索还必须同时限定 knowledge_base_id。跨租户知识库统一表现为不存在，不能泄漏对象状态。

受管检索只接受 MySQL 中当前状态为 ready 的文档版本。processing、failed、superseded、deleted 版本和缺少稳定身份的旧格式向量都不能进入模型上下文或引用。

4.0.0 中旧格式向量不能用于检索或引用，必须通过预置加载或文件上传重新导入后才能成为受管证据。

引用只允许来自本轮实际召回证据。伪造、越界或不属于本轮召回的编号会被丢弃。每轮最多八条引用，单条摘要最多五百字符，引用 JSON 不超过 32 KiB。前端使用文本节点展示来源和摘要，不能执行其中的标签、链接或脚本。
